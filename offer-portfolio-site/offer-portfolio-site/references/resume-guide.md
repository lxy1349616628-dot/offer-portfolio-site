# 简历优化指南

在生成网站之前使用。目标是让简历更具体、更可信，不是让它更好听。

## 1. 诊断

逐条读工作经历、项目经历和技能，按下面的问题挑毛病，每条问题都要指到原文具体那一句：

| 问题 | 典型写法 | 要改成 |
|---|---|---|
| 只有动作，没有结果 | 负责公司抖音账号运营 | 运营门店抖音号6个月，涨粉1.2万，带动到店核销800单 |
| 数字没有口径 | 播放量10万+ | 单条视频最高播放14.4万（抖音） |
| 套话 | 具备良好的沟通能力和团队精神 | 删掉，或换成一件能证明它的具体事 |
| 动词太弱 | 参与、协助、配合 | 有主导就写主导；确实是协助，写清协助了哪一块、产出是什么 |
| 和目标岗位对不上 | 投AI产品岗，却只写了拍摄剪辑 | 把产品相关的经历提前、写细，无关的压缩 |
| AI分工不清 | 独立开发了一款应用 | 说清哪些是自己做的（需求、设计、提示词、测试），哪些交给了AI |
| 时间、名称前后不一致 | 同一个作品两个名字，时间段重叠 | 统一 |

另外检查：
- 每段经历的第一条，是不是这段经历最强的结果
- 技能栏有没有写具体工具和熟练程度
- 有没有手机号以外不必要的隐私（身份证号、详细住址、婚育状况），有就建议删掉

## 2. 追问

把诊断出的缺口变成问题，一次问完，最多八个。只问对方能回答的事实，例如：

- 这个账号做了多久？接手时多少粉，现在多少？
- “客流翻倍”是怎么算的，对比的是哪段时间？
- 这个产品现在有人在用吗？大概多少人、用了多久？
- 投的是哪类岗位？招聘要求里最常出现哪几个词？

对方答不上来的，就不要写那个数字，换成能说清的事实，或者直接删掉。

## 3. 改写

按目标岗位出一版优化稿，规则：

- **只用对方材料里的事实和追问得到的回答。** 不补数字，不升级职位，不把“参与”写成“主导”。缺的地方写 `[待补充：xxx]`。
- 每条经历按“做了什么 + 怎么做 + 结果”写，一条一行，一行不超过两句。
- 每段经历三到五条，最强的放第一条。
- 投多个方向时，分版本写，每版调整经历的顺序和详略，事实保持一致。
- 保留对方原有的结构和语气习惯，不要整篇换成另一种风格。

## 4. 交付

- 输出 `resume-optimized.md`：先列“改了什么、为什么”（只列重要的，五条以内），再放完整的优化稿。
- 对方要Word或PDF时，再用对应的文档技能生成，排版尽量沿用原简历。
- 对方确认后，网站的首屏数字、能力版图、作品卡全部从优化稿取数，保证简历和网站说的是同一套话。
